# Game examples

These 40 small images and `manifest.json` are **not part of Spire UI**. They are not in the shadcn
registry, not in the `spire-ui` npm package, and are not offered as a download.

- **Origin:** icons extracted from Slay the Spire 2 by Mega Crit, produced by this project's
  `spire-ui extract-art` CLI from the owner's own copy of the game (game version in `manifest.json`).
  The art belongs to Mega Crit.
- **Purpose:** only to illustrate the components on the docs site ("With your game's art" previews and
  the Storybook "Game art: examples" toggle). The owner of this repository relies on fair use for this
  small, curated set.
- **What is here:** the five class icons, the room icons, the top bar stat icons, six potions and
  eighteen relics. The manifest keeps the CLI's schema, `generator` field and item names and
  descriptions for these items only. It does not record rarity, so relics were picked as a varied set.
- **No fonts** are included.

Unofficial fan project, not affiliated with Mega Crit. Do not copy these files into your own project;
extract your own with `npx spire-ui extract-art`.
