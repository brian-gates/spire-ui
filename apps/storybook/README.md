# Spire UI Storybook

Visual workbench for the kit. Run from the repo root:

```sh
bun run storybook          # dev server on http://localhost:6006
bun run storybook:build    # static build in apps/storybook/storybook-static
```

Stories live in `stories/` (never in `registry/`, which is what users install).
Tasks 5 to 7 add game components under the `Game/` group.
